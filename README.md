# Project1_GUI_autopark
Данный проект представляет собой объектно-ориентированное приложение с графическим интерфейсом пользователя, разработанное на языке Java. Приложение предназначено для ведения базы данных автомобилей, выполнения операций добавления, редактирования, удаления, а также сложных запросов (фильтрация, сортировка, выборка по диапазону).
